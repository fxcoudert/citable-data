**Data, scripts, input files**

- [`MACE_ZIF4_stress100.model`](MACE_ZIF4_stress100.model): MACE machine-learnt potential trained and used in the work
- [`MACE_ZIF4_stress100_compiled.model`](MACE_ZIF4_stress100_compiled.model): same model, compiled
- [`train_mace`](train_mace): MACE training script
- [`flathist.xyz.gz`](flathist.xyz.gz): data set on which the MLP is trained, generated by _ab initio_ molecular dynamics. This data set was first generated and reported in .
- [`melt_quench.in`](melt_quench.in): LAMMPS input file for a melt-quench MD simulation.
- [`ZIF_4_NVT.restart`](ZIF_4_NVT.restart): LAMMPS restart file, initial configuration for simulation above.
- [`ZIF4_CPII.in`](ZIF4_CPII.in): LAMMPS input file for a constant-pressure MD simulation.
- [`ZIF4_NPT.restart`](ZIF4_NPT.restart): LAMMPS restart file, initial configuration for simulation above.
